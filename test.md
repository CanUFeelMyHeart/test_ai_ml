# Инструкция по работе с Git

## 1. Создание репозитория
Чтобы создать пустой репозиторий, используем команду:  
> **git init** - инициализация репозитория.

## 2. Добавление файла в отслеживание и коммит

> **git add filemame** - добавить в отслеживание файл с именем *filemame*
> или **git add .** - добавить в отслеживание все измененные файлы
> **git commit -m message** - создание коммита.

> ##. Работа с ветками

> **git branch** - просмотр всех веток в репозитории  
> **git branch branc_name** - перейти в ветку с именем *branch_name*
